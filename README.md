## Hello! Welcome to my simple Calendar application!

This application runs on your browser (typically http://localhost:5173/) using Vite, React and Typescript.

Its fairly simple, I just couldn't be bothered to download an actual app or use Outlook calendar.

Data is saved on the browser and can be lost when the cache is cleared

Run "run-calendar.bat" to start the local server. Note that Node.js (V24.21.0) will need to be installed

I might add more functionality to this in the future
