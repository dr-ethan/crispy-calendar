## Hello! Welcome to my simple Calendar application!

This application runs on your browser (under http://localhost:5173/) using Vite, React and Typescript.

Its fairly simple, I just couldn't be bothered to download an actual app or use Outlook calendar.

Data is saved on the browser and can be lost when the cache is cleared

Run "run-calendar.bat" to start the server. Note that Node.js (V24.21.0) will need to be installed
